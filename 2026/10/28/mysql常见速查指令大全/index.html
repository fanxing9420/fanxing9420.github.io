MYSQL常见速查指令大全

数据库连接与管理

连接到服务器：mysql -u username -p

使用命令行连接到 MySQL 服务器。

数据库操作：CREATE / DROP / USE

管理服务器上的数据库。

导出数据：mysqldump

将数据库数据备份到 SQL 文件。

导入数据：mysql < file.sql

将 SQL 文件导入到 MySQL 数据库中。

用户管理：CREATE USER / GRANT

管理数据库用户和权限。

显示服务器信息：SHOW STATUS / SHOW VARIABLES

显示服务器配置和状态。

表结构与模式

创建表：CREATE TABLE

使用指定的列和数据类型创建新表。

表信息：DESCRIBE / SHOW

查看表结构和数据库内容。

修改表：ALTER TABLE

更改现有表结构，添加或删除列。

数据操作与 CRUD 操作

插入数据：INSERT INTO

向表中添加新记录。

更新数据：UPDATE

修改表中的现有记录。

删除数据：DELETE / TRUNCATE

从表中删除记录。

替换数据：REPLACE / INSERT ... ON DUPLICATE KEY

处理插入期间的重复键情况。

数据查询与选择

基本 SELECT: SELECT * FROM

检索具有各种条件的数据。

排序与限制：ORDER BY / LIMIT

控制返回结果的顺序和数量。

筛选：WHERE / LIKE / IN

使用各种比较运算符过滤数据。

分组：GROUP BY / HAVING

对数据进行分组并应用聚合函数。

高级查询

JOIN 操作：INNER / LEFT / RIGHT

合并来自多个表的数据。

子查询：SELECT within SELECT

使用嵌套查询来检索复杂数据。

聚合函数：COUNT / SUM / AVG

从数据中计算统计信息和摘要。

窗口函数：OVER / PARTITION BY

在行集上执行计算。

索引与性能

创建索引：CREATE INDEX

使用数据库索引提高查询性能。

查询分析：EXPLAIN

分析查询执行计划和性能。

优化查询：最佳实践

编写高效 SQL 查询的技术。

表维护：OPTIMIZE / ANALYZE

维护表性能和统计信息。

数据导入/导出

加载数据：LOAD DATA INFILE

从 CSV 和文本文件导入数据。

导出数据：SELECT INTO OUTFILE

将查询结果导出到文件。

备份与恢复：mysqldump / mysql

创建和恢复数据库备份。

数据类型与函数

常见数据类型：数字、文本、日期

为列选择适当的数据类型。

字符串函数：CONCAT / SUBSTRING / LENGTH

使用内置字符串函数操作文本数据。

日期函数：NOW() / DATE_ADD / DATEDIFF

有效地处理日期和时间。

数值函数：ROUND / ABS / RAND

对数值数据执行数学运算。

事务管理

事务控制：BEGIN / COMMIT / ROLLBACK

管理数据库事务以确保数据一致性。

事务隔离级别：SET TRANSACTION ISOLATION

控制事务之间如何相互作用。

锁定：LOCK TABLES / SELECT FOR UPDATE

控制对数据的并发访问。

保存点：SAVEPOINT / ROLLBACK TO

在事务内部创建回滚点。

高级 SQL 技术

公用表表达式 (CTEs): WITH

创建临时结果集以用于复杂查询。

存储过程：CREATE PROCEDURE

创建可重用的数据库过程。

触发器：CREATE TRIGGER

对数据库事件做出响应自动执行代码。

视图：CREATE VIEW

基于查询结果创建虚拟表。

MySQL 安装与设置

安装：包管理器

使用系统包管理器安装 MySQL。

Docker: docker run mysql

在 Docker 容器中运行 MySQL 以进行开发。

初始设置与安全

保护您的 MySQL 安装并验证设置。

配置与设置

配置文件：my.cnf

修改 MySQL 服务器配置设置。

运行时配置：SET GLOBAL

在 MySQL 运行时更改设置。

性能调优：内存与缓存

优化 MySQL 性能设置。

日志配置：错误与查询日志

配置 MySQL 日志以进行监控和调试。
